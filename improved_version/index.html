Do Q-learning agents learn to collude?

Two independent learning algorithms play the same game over and over, with no communication. Do they find the equilibrium, a price war, or quiet cooperation? Everything on this page runs live in your browser: pick a game, change a parameter and watch what the agents learn.

The big idea, in 30 seconds

Imagine two online shops whose pricing bots keep adjusting prices to earn more. Each bot only sees the last round (what both shops did) and the profit it just got. It slowly learns "in situation S, action A tends to pay X". That is Q-learning.

Each game below is a tiny stand-in for a pricing decision: Cooperate = keep the price high, Defect = undercut. The question is whether the two learners settle on a Nash equilibrium (nobody gains by switching alone), or on something else, such as tacit collusion, where they keep prices high without ever agreeing to.

The key lever is the discount factor γ: how much a learner cares about future profit. If γ = 0 it is purely short-sighted. If γ is large it can learn that undercutting today triggers a price war tomorrow.

If Player 2 retaliates and cooperation later resumes, the high outcome is held up by a threat of punishment, the signature of genuine algorithmic collusion rather than a lucky coincidence.

6Measuring collusion

Not applicable for this game. The collusion measures compare the outcome with the one-shot Nash outcome, which only makes sense in the Prisoner's Dilemma, where the cooperative outcome (C, C) is not itself an equilibrium. In the Stag Hunt and Coordination games, (C, C) is an equilibrium, so landing there is coordination, not collusion. Switch the game to Prisoner's Dilemma to use this section.
How to read this: "different from Nash" is not enough on its own. Each run is measured with the collusion index Δ = (average payoff − Nash payoff) / (cooperative payoff − Nash payoff) (0 = competitive, 1 = full cooperation) and then classified by also checking whether cheating is punished:

8How it works (and what to be careful about)

The learning rule

Each player keeps a table Q[state][action]: its current estimate of how good an action is in a state. After every period it nudges one entry toward what it just observed:

Q[s][a] ← Q[s][a] + α · ( r + γ · maxa' Q[s'][a'] − Q[s][a] )

s = last round's pair of actions, a = what I played, r = profit received, s' = the new state, α = learning rate, γ = discount factor.

To keep learning, a player sometimes plays a random action (ε-greedy). Exploration starts at 100% and decays exponentially, εt = e−decay·t. A run stops early once exploration is low and both strategies have stopped changing.

Nash equilibrium
A pair of actions where neither player gains by switching on their own.
Tacit collusion
Keeping outcomes better for both than the equilibrium, with no communication, only because each side expects the other to punish cheating.
Collusion index Δ
Δ = (π̄ − πNash) / (πcoop − πNash). It is 0 at the competitive (Nash) payoff and 1 at the fully cooperative payoff. In the Prisoner's Dilemma, Δ is simply the average payoff per player. It is high only if the outcome beats Nash; whether it is collusion additionally needs the deviation to be punished.
Wilson confidence interval
The range of true rates consistent with the observed share of runs. With 100 runs, a 26% rate is roughly 18–35%; with 20 runs the range is about twice as wide.
Payoff-dominant vs risk-dominant
In the stag hunt, (C, C) pays most but (D, D) is safer. D is the risk-dominant choice when G < 1 (the point where C's chance of a 1+G payoff no longer beats the safe 1 at 50/50 odds).
Self-confirming outcome
Once exploration fades, an off-path action is rarely tried again, so a wrong, pessimistic estimate of it is never corrected. That is why some runs end at outcomes that are not Nash (for example Hawk-Dove with a small G).

Honest limitations

  • These are toy 2-player games with a 1-round memory, not a real pricing market. Real-world claims need richer models (e.g. Bertrand competition with many prices).
  • Q-learning's convergence guarantees assume a fixed environment. Here the opponent is learning too, so results are empirical and seed-dependent. That is why we run many seeds.
  • The collusion measures are defined for the Prisoner's Dilemma only, and the deviation test is run from one state of the settled outcome. A positive result in one run is not proof; look at rates over many runs.
  • Results depend on settings such as α, how fast exploration decays and the initial Q-values.
  • This browser engine is a JavaScript port of qlearning_games.py (same algorithm, different random numbers), so exact percentages differ slightly from the Python output.
